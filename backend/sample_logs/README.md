# SentinelX — Sample security logs

Realistic sample log files used by the controlled security lab and for
demonstrating the log ingestion pipeline. These files contain **simulated**
events only — they are for local demonstration and testing on systems the
developer owns or is authorised to test.

- `ssh.log` — SSH authentication logs including brute-force activity
- `apache.log` — Apache-style HTTP access logs
- `auth.log` — Linux authentication logs including sudo usage
